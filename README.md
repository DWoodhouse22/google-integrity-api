# Google Play Integrity API
HTTP server to handle Google Play Integrity API requests

# Note
If you have stumbled upon this repo today, it's very early on and does not currently contain all the features required for a full end-to-end implementation of the integrity API.  Feel free to follow along this journey as it gets fleshed out.

## Usage
### Setup
Set the following environment variables:  
`GOOGLE_SERVICE_ACCOUNT_JSON` - key JSON generated for a service account with access to the Google Play Integrity API [docs](https://developer.android.com/google/play/integrity/setup#set-integrity-responses)  
`APP_PACKAGE_NAME` - Package name for you app, must match what is set in the Google Play Console  
`APP_SIGNING_CERT` - The SHA-256 certificate fingerprint of your signing certificate. NOTE: If your app is signed by Google, on the Play Console get this from: `Test and Release` -> `App Integrity` -> `Play app signing` -> `Settings`
### Start the server
`go run ./cmd/server/`

#### Generate new one-time token
```bash
$ curl localhost:8080/token/generate
{"token":"NuaA7Aw3zKpUERwk0lnrKioCfNGnfvdmSUFOMtbzP0s="}
```

#### On the client side call Google's integrity API for a verdict token

#### Verify
```bash
$ curl -X POST http://localhost:8080/integrity/verify-token \
  -H "Content-Type: application/json" \
  -d '{"token":"<Token generated by client integrity api>"}'
{"verdict":valid}
```
